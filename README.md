No Capstone Project do IBM Data Science Professional Certificate, trabalhei com dados reais da SpaceX para analisar e prever o sucesso de lançamentos espaciais. Meu objetivo foi explorar um conjunto de dados históricos, identificando padrões que influenciam o sucesso dos lançamentos, analisando custos e avaliando o impacto das diferentes plataformas de lançamento.

Utilizei Python e bibliotecas como Pandas, Matplotlib, Seaborn e Folium para realizar extração, limpeza e visualização de dados geoespaciais. Além disso, apliquei técnicas de Machine Learning, usando Scikit-Learn para treinar modelos preditivos, como regressão logística e árvore de decisão, a fim de estimar a probabilidade de sucesso de futuros lançamentos.

Esse projeto me permitiu aprofundar habilidades em data wrangling, análise exploratória e modelagem preditiva, além de reforçar a importância da interpretação de dados e storytelling para apoiar a tomada de decisões.
